# Security

If you find a security problem in this package or in the hosted service at
snapdiff.ai, please tell us privately. Don't open a public issue.

You can [report it on GitHub](https://github.com/corralimited/snapdiff-mcp/security/advisories/new)
or email security.snapdiff@corralimited.com.

We'll reply within 5 business days. Fixes go into the latest release only.
